# Паттерн-ориентированный экстрактор отношений

Этот модуль заменяет нейросетевой классификатор отношений детерминированными синтаксическими шаблонами.

## Идея

Вместо обучения модели на размеченных данных, мы задаём списки шаблонных фраз для каждого типа отношений (например, «является частью», «входит в состав»). Затем с помощью DSL DiGr ищем предложения (или другие контекстные окна), где одновременно встречаются два термина и одна из шаблонных фраз.

## Структура

- `extractor.py` – класс `PatternBasedRelationExtractor`.
- `templates.yaml` – конфигурация шаблонов.
- `run.py` – скрипт для запуска.

## Использование

1. Установите зависимости (DiGr уже должен быть настроен).
2. Запустите из корня проекта:

```bash
PYTHONPATH=src python relation_extractor/run.py --tex GA_1_2025.tex --format tex --out relations.json
